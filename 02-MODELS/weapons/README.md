# Armes 3D

## Armes disponibles
- `sword-meshy.glb` : épée Meshy légère utilisée actuellement comme modèle provisoire dans le prototype.
- `Meshy_AI_A_divine_red_sword_fo_1018004643_texture_fbx.zip` et `Meshy_AI_A_divine_red_sword_fo_1018004744_texture_fbx.zip` : archives originales de l'épée divine rouge, conservées.
- `source-divine-sword/` : fichiers FBX extraits des deux archives. Ce sont des sources, pas encore le modèle chargé dans le jeu.
- Les textures PBR extraites sont rangées dans `03-TEXTURES/weapons/divine-sword/` : albedo, metallic, normal et roughness.

## Étape avant l'intégration en jeu
Convertir une des sources FBX en GLB en conservant ses matériaux/textures, vérifier le résultat, puis l'intégrer au prototype et valider son point d'attache dans la main du personnage. Ne pas supprimer les ZIP originaux ni le modèle provisoire avant validation.

# Procédure d'intégration des assets Meshy

## Assets ciblés
- Personnage principal ASTREA (GLB)
- Animation de course du personnage (source à vérifier)
- Épée divine (GLB)

## Procédure
1. Ajouter les fichiers sources dans le dossier de catégorie correspondant.
2. Vérifier que chaque fichier est réellement présent dans GitHub et que sa taille est plausible.
3. Tester le chargement du GLB avec un chargeur compatible glTF/GLB.
4. Vérifier matériaux, textures, orientation, échelle et pivot.
5. Vérifier que l'animation utilise un squelette compatible avec le personnage.
6. Ajouter le chemin exact, le format et le résultat du test à `LISTE-ASSETS.md`.
7. Remplacer le placeholder dans le jeu seulement après réussite du test.

# Textures ASTREA REBORN

Les packs ZIP originaux restent conservés dans `environment/`. Leurs fichiers ont aussi été extraits dans les catégories ci-dessous pour faciliter leur utilisation.

- `terrain/` : herbe, terre, roche, pavage et sable.
- `vegetation/` : atlas de fleurs et végétation.
- `buildings/` : bois, murs, enduits, pierre et sols intérieurs.
- `characters/` : textures spécifiques aux personnages quand elles seront disponibles.
- `environment/` : ciel, aperçu et packs source ambigus ou généraux.
- `effects/` : effets visuels et éléments.
- `weapons/divine-sword/` : textures PBR des deux variantes de l'épée divine rouge.

Avant de charger une texture en jeu, vérifier son rôle (albedo/base color, normal, metallic ou roughness). Les cartes normal/metallic/roughness ne doivent pas être appliquées comme couleur de base. Optimiser la résolution pour les appareils Android et n'activer que les ressources utilisées par la scène.
